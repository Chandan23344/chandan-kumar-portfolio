## Real-Time Concentration Monitor
The project description is based on the supplied RIT project presentation. It uses:
- Python
- OpenCV
- MediaPipe Face Mesh
- NumPy
- `collections.deque`
- `time`

The system captures webcam frames, detects facial landmarks, estimates head pose
(pitch, yaw and roll), detects blinks using Eye Aspect Ratio (EAR), estimates gaze
direction, classifies focused/distracted states, maintains a recent-frame history,
calculates concentration percentage, and overlays status, concentration percentage,
FPS and a progress bar on the video.

The supplied presentation also shows a workflow involving camera input, student,
action/behavior detection, emotion detection, face detection/recognition, attendance,
attention score/live graph, and CSV data output. These items should only be presented
as portfolio features if they are part of the actual implemented version.
